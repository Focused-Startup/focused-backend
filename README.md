# focused-backend

Barebone Express backend.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

Or run without auto-reload:

```bash
npm start
```

## Swagger

After the server is running, open:

```text
http://localhost:3000/api-docs
```

The OpenAPI JSON is also available at:

```text
http://localhost:3000/api-docs.json
```
